PrevenTech - Sistema de Controle de Preventivas de TI





Sobre o Projeto

O PrevenTech é um sistema desenvolvido para controle e gerenciamento de manutenções preventivas de equipamentos de TI, permitindo organizar notebooks e desktops por setores, acompanhar históricos de manutenção e melhorar o controle do parque tecnológico de uma empresa.

O objetivo é facilitar o trabalho da equipe de suporte técnico, proporcionando uma visão completa dos equipamentos, suas condições e próximas manutenções.

Funcionalidades
Cadastro de Setores
Cadastro de setores da empresa
Responsável pelo setor
Localização
Observações
Organização dos equipamentos por departamento
